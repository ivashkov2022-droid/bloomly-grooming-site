# Bloomly Grooming Site

A clean code recreation of the Bloomly pet-grooming landing page exported from Tilda. The implementation is built with React, TypeScript, Vinext, and the OpenAI Sites hosting runtime.

## Live website

https://ivashkov2022-droid.github.io/bloomly-grooming-site/

The public repository and GitHub Pages deployment are owned by the `ivashkov2022-droid` account.

VPS showcase: https://vazuri.ru/bloomly-7q4m9x2/

The Vazuri route is an isolated, non-indexed showcase served by the new VPS. It does not replace or modify the Vazuri website files.

## Included

- Responsive single-page layout matching the Tilda reference
- Original Bloomly imagery and visual language
- Services, studio, offers, gallery, reviews, FAQ, booking, and footer sections
- Interactive FAQ and booking confirmation state
- Social sharing preview artwork

## Local development

```bash
pnpm install
pnpm run dev
```

## Production build

```bash
pnpm run build
```

The source archive and original Tilda runtime are not required to run this project.
